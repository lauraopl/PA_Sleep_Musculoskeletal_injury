# Determining physical activity and sleep over 12 months after a musculoskeletal injury

## Overview

This repository contains the R scripts used to process and analyse accelerometer-derived physical activity and sleep data for the following study:

**Fisher, E., Collard, V., Oporto-Lisboa, L., White, V., Monsell, F., Clinch, J., & Eccleston, C. (2026).** *Determining physical activity and sleep over 12 months after a musculoskeletal injury.*

The study investigates patterns of physical activity and sleep in children and adolescents following an acute musculoskeletal injury, examining changes over a 12-month recovery period. In addition, it aims to determine if we can predict physical activity and sleep using self-reported pain, anxiety, depression, and parent protectiveness measures.

The repository provides the code used for processing raw accelerometer data and conducting the subsequent analyses reported in the paper.

## Repository contents

The analysis is organised into two main stages: processing raw accelerometer data and analysing the processed outputs alongside additional participant information.

| File | Description |
|---|---|
| `analysing_bin_files.R` | Processes raw Actiwatch accelerometer data (`.bin` files) using the [GGIR](https://wadpac.github.io/GGIR/) R package. |
| `Analysis_GGIR_outputs` | Main analysis script, using processed GGIR outputs alongside participant completion information and questionnaire data. |

## Analysis workflow

### 1. Accelerometer data processing

**Script:** `analysing_bin_files.R`

Raw accelerometer recordings are processed using the GGIR R package, which supports the analysis of physical activity and sleep from wearable accelerometer data.

- **Input:** A directory containing raw Actiwatch `.bin` files.
- **Processing:** Accelerometer data are processed using GGIR.
- **Output:** Processed data files generated by GGIR for subsequent analysis.

Further information about GGIR and its output files can be found in the [GGIR documentation](https://wadpac.github.io/GGIR/).

### 2. Analysis of physical activity and sleep

**Script:** `Analysis_GGIR_outputs`

This script conducts the main analyses using the processed accelerometer data and additional study information.

- **Inputs:** GGIR output files, participant completion data, and questionnaire results.
- **Purpose:** To analyse physical activity and sleep outcomes over the 12-month follow-up period.
- **Outputs:** Results used to inform the analyses presented in the associated publication.

## Software requirements

Analyses were conducted in R version 4.5.2.

The primary package used for processing accelerometer data is:

- [GGIR](https://cran.r-project.org/package=GGIR) — processing and analysis of raw accelerometer data.

Additional R package dependencies can be identified in the individual analysis scripts.
